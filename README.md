# Matt Stowers Portfolio

Personal portfolio for Matt Stowers. Built with Next.js, JavaScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Production build

```bash
npm run build
npm run start
```

The site is deployable to Vercel without database, CMS, payment, authentication, or AI service credentials.

## Portfolio assets

- `src/assets/image_a0b48ef7.jpg` is the professional headshot used on the homepage.
- `public/matt-stowers-resume.pdf` is the downloadable resume.

Portfolio details and palette guidance are in `spec.md`; notable design decisions are recorded in `decision.md`.
